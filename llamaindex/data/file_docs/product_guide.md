# LinAI Box 产品手册

LinAI Box 支持把产品手册、运维策略、故障复盘和指标说明导入本地知识库。

这份手册面向一线运维和平台开发人员，主要说明索引发布、查询服务、故障码和权限策略。

## 索引发布

索引发布分为四个阶段：

1. `parse`：解析上传文件，得到 Markdown、纯文本或表格行。
2. `chunk`：根据文件类型选择切块策略。
3. `embed`：生成向量并写入向量库。
4. `publish`：将索引版本标记为 `published`。

索引构建任务完成后，查询服务会加载最新的 `published` 索引版本。

如果新文档上传后没有立即出现在问答结果里，先检查 ingestion job 是否完成，再检查查询服务加载的索引版本。

## 故障码

| 故障码 | 含义 | 处理建议 |
| --- | --- | --- |
| E-401 | 权限不足 | 检查用户分组和文档 visibility |
| E-503 | 索引构建任务未完成 | 先检查 ingestion job 状态 |
| E-920 | 文件解析结果为空 | 检查 parser 日志和文件格式 |
| E-931 | 表格字段缺失 | 检查 CSV/Excel 表头和字段映射 |

## 权限策略

每个入库 `Document` 都应该保留 `tenant_id`、`visibility` 和 `source`。

如果 metadata 缺失，检索阶段就很难做权限过滤。不要把权限判断完全放到回答生成之后。

## 上线检查

上线前至少检查三件事：

- 入库文件是否都有 `document_id`。
- 每个 Node 是否能回到原始文件。
- 解析失败的文件是否被阻断，而不是混进索引。
