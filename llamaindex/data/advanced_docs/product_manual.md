# 产品知识库示例

LinAI Box 是一个本地知识库设备，主要用于家庭和小团队的数据检索。

设备支持本地文档索引、权限分组、定时重建索引和检索日志记录。

如果用户问到设备重启后索引是否会丢失，答案应该来自持久化索引配置，而不是临时内存索引。

常见故障码：

- E-401：用户没有访问当前文档分组的权限。
- E-503：索引构建任务未完成，查询服务只能访问旧版本索引。
- E-920：PDF 解析结果为空，通常和扫描件或图片型 PDF 有关。

客服处理规则：

1. 如果问题和权限有关，先确认用户所在分组。
2. 如果问题和检索不到文档有关，先检查索引任务是否完成。
3. 如果问题和 PDF 内容缺失有关，先检查解析结果，再检查 Retriever。
